# 随机数抽号器（Android PWA）设计文档

日期：2026-09-05
状态：已确认（用户批准）

## 目标

一个安卓端随机数抽取工具，以 PWA 形式交付：

- 抽取结果数字放大到占满整个屏幕。
- 点击屏幕任意位置重新抽取。
- 抽取前播放幸运大转盘动画（旋转、缓出减速、停下）。
- 数字范围可自行设置。

## 交付形式

单个自包含 HTML 文件（`index.html`），零外部依赖，离线可用。

- 手机端：将文件传到手机 → Chrome 打开 → 菜单「添加到主屏幕」→ 桌面图标全屏启动。
- 内联 PWA manifest（data URL）+ theme-color + viewport-fit=cover。
- 首次点击调用 Fullscreen API 请求全屏，失败时静默降级。

## 交互状态机

### 1. 转盘场景（idle / spinning）

- 视觉风格：糖果渐变风——8 色粉彩径向渐变扇区（中心饱和、外缘浅）、白色圆头分隔线、固定不随盘面旋转的玻璃质感高光弧、圆形柔和投影、白色外圈与白色渐变中心盘（深色数字）、粉色指针、径向渐变深色背景。
- Canvas 绘制大转盘，居中，约占屏宽 90%；彩色扇区，顶部固定指针。
- 转盘中央滚动闪现候选数字。
- 底部提示「点一下屏幕开始」。
- 点击（idle 时）：转盘加速旋转 5–8 圈，总时长约 3.5s，ease-out 减速停下；随机落点。
- 转动中（spinning）点击无效（防误触）。
- 停止后约 0.3s 切换到结果场景。

### 2. 结果场景（result）

- 结果数字按屏幕宽高自适应取最大字号，占满屏幕。
- 马卡龙配色：背景为结果色相的浅粉彩（hsl h 80% 88%），数字用同色相深色调（hsl h 62% 30%），与糖果转盘风格呼应。
- 底部小字「点击屏幕再抽一次」。
- 点击任意处 → 回到转盘场景并自动开始旋转（新一轮抽取）。

### 3. 设置弹层（settings）

- 右上角小齿轮打开。
- 起止数字输入（默认 1–100），非法输入（min > max、非整数、超界 1–9999）红字提示且不生效。
- 开关「不重复抽取」：抽过的号不再出现；剩余池抽空时提示并引导重置。
- 最近 20 条抽取记录列表，可一键清空。
- 设置持久化到 localStorage。

## 数据流

- `Settings`（min、max、不重复开关）→ localStorage。
- 随机数：`crypto.getRandomValues` 拒绝采样，保证 [min, max] 均匀无偏差。
- 「不重复抽取」开启时：剩余池存 localStorage，每次从池中移除已抽号码。
- `History`（最近 20 条）→ localStorage。
- localStorage 不可用（如 file:// 某些环境）时降级为内存存储，功能不受影响，仅不持久化。

## 错误处理

- localStorage 读写 try/catch，失败降级内存。
- Fullscreen API 调用包 try/catch，失败静默。
- 设置输入校验：整数、1–9999、min ≤ max；不合法红字提示、不保存。
- 不重复模式下池抽空：弹层提示已抽完全部号码，一键重置池。

## 测试计划（本机浏览器验证）

- 转盘动画流畅（rAF 驱动，无卡顿）。
- 完整流程：点击 → 旋转 → 停止 → 结果全屏数字 → 点击 → 再抽。
- 转动中点击无效。
- 范围边界：min > max 提示；min == max（单值范围）正常抽取；1–1。
- 不重复模式：抽过不重现、抽空提示重置。
- 结果字号在窄屏（竖屏）与宽屏下均撑满且不溢出。
- localStorage 降级路径（模拟抛异常）不崩溃。

## 明确不做（YAGNI）

- 原生 Android 工程 / APK 打包。
- 语音播报、姓名点名模式、多组标签。
- 服务端同步。
